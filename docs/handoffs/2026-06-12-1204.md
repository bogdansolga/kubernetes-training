## 4. Decisions & rationale

- **Building blocks only** — labs teach one resource in isolation; the labs repo never ships a
  fully-wired SkyHop (that's the capstone's job). Brief-disclosed facts are fair game; the assembled
  solution is not.
- **One Kubernetes resource per file** (user directive) — split Service/StatefulSet, PV/PVC/Pod,
  cronjob PVC/CronJob, RBAC role/binding, etc.
- **Namespace-less by default** — most labs apply to `default` so each runs standalone; only
  `namespace`, `resource-quota`, `roles` use `skyhop`.
- **DaemonSet = node-exporter, not a toy** — there is *no* SkyHop-app use-case for a DaemonSet (SkyHop
  tiers are replica-scaled); it's node-level infra, so it shows a real agent.
- **Job and CronJob are both DB backup** (one-off vs scheduled) — clean Job-vs-CronJob contrast.
- **TLS termination is a d03 stretch, Caddy as the *edge*** — real-world TLS terminates once at the
  shared edge (Ingress/Gateway/LB), not a per-app proxy; in-cluster encryption = service mesh.
- **Monitoring scrapes OUR node-exporter** (dns_sd, no operator) + KSM for HPA/object metrics; cAdvisor
  left as documented optional to avoid the RBAC/kubelet-TLS weight.
- **timeline.svg exists because GitHub renders SVG but not HTML** — keep both in sync.

## 6. Gotchas

- `postgres:18-alpine` needs `PGDATA=/var/lib/postgresql/data/pgdata` (subPath `pgdata`) or it aborts.
- **metrics-server** on kind needs `--kubelet-insecure-tls` (else `/readyz` probe fails → NotReady).
- **HPA** needs container `requests` + metrics-server. Load via `d03/autoscaling/load-test.sh <users>`.
- **NetworkPolicy IS enforced** by kindnet here (deny test really denies).
- **Gateway API:** CRDs v1.5.0 + NGINX Gateway Fabric v2.6.3; min K8s 1.26. Test via port-forward of
  `svc/skyhop-gateway-nginx`.
- **TLS cert is chosen by SNI** — test with `curl --resolve host:port:ip`, NOT a `Host:` header.
- **Prometheus reloads config only at startup** — after editing `prometheus-config.yml`,
  `kubectl rollout restart deploy/prometheus`.
- **Editing a tracked README/manifest** requires reading it first (harness). Several files were
  untracked until committed → `git mv` fails on them; use plain `mv`.
- `.DS_Store` is gitignored — don't let it sneak into commits.
